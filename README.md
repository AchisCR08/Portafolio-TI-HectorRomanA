# Mi portafolio de Tecnologías de Información

Soy estudiante del Diplomado en Tecnologías de Información y aquí reúno proyectos académicos que he trabajado durante la carrera. Los organicé en carpetas separadas para explicar qué hace cada uno, qué tecnologías aparecen en el código y cómo prepararlo para ejecutarlo.

## Proyectos

- [API REST de seguridad](proyectos/01-api-seguridad-rest/README.md) — la desarrollé individualmente para Programación V.
- [Telefonía: servicios y portal](proyectos/02-telefonia-servicios-y-portal/README.md) — trabajo grupal; mi aporte principal fue la autenticación conectada a MongoDB.
- [Telefonía: Alcance 2](proyectos/03-telefonia-alcance-2/README.md) — entrega grupal; participé en componentes de autenticación/MongoDB y debo confirmar el alcance exacto.
- [Taller Todo Terreno](proyectos/04-taller-todo-terreno/README.md) — tarea corta académica; debo confirmar mis componentes específicos antes de atribuirme módulos.
- [Sistema veterinario](proyectos/05-sistema-veterinaria/README.md) — proyecto grupal; desarrollé el módulo de clínica, incluida la interfaz y objetos de base de datos asociados.
- [Sistema de telefonía: proyecto final](proyectos/06-telefonia-proyecto-final/README.md) — proyecto final grupal de Programación IV; todavía debo precisar qué partes hice yo.

## Tecnologías que he utilizado

C#/.NET, ASP.NET MVC, servicios REST y WCF/SOAP, SQL Server, MongoDB, Python, Java, Postman, Swagger, Entity Framework Core, Dapper, procedimientos almacenados, vistas y triggers.
